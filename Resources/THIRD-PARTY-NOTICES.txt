GKMD third-party notices
========================

GKMD bundles the following third-party component. This notice is
embedded in GKMD.dll and written to disk alongside the component
whenever GKMD deploys it.

--------------------------------------------------------------------
usbip-win2 (version 0.9.8.0)
https://github.com/vadimgrn/usbip-win2
--------------------------------------------------------------------

Used as the USB transport for GKMD's virtual USB personas (profiles
that present USB Audio Class interfaces alongside HID). A Windows audio
endpoint requires a driver-backed USB device, which no user-mode API can
create, so GKMD speaks the USB/IP protocol to usbip-win2's virtual host
controller. Every device behavior remains in GKMD's own user-mode code.

The redistributed binary is the upstream release asset
USBip-0.9.8.0-x64.exe, unmodified, SHA256:
81f426741f7ee2ed991febe24a22daca8400b6ae2f171054e3fb404897e15d39
